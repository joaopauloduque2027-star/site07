# Meu estúdio de música

Este projeto é um site pessoal em HTML, CSS e JavaScript para apresentar a minha jornada musical, minhas redes sociais e a história por trás do meu trabalho como músico.

## Como visualizar

1. Abra o arquivo `index.html` diretamente no navegador, ou
2. Use um servidor local simples:

```bash
python -m http.server 8000
```

Depois acesse: http://localhost:8000

## Estrutura do projeto

```text
.
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── script.js
│   └── img/
│       └── .gitkeep
├── .gitignore
└── README.md
```

## Publicar no GitHub Pages

1. Vá em Settings → Pages no repositório.
2. Em "Source", escolha a branch desejada e a pasta raiz `/`.
3. Salve. O site ficará disponível em um endereço do tipo:
   `https://joaopauloduque2027-star.github.io/site07/`

## Observações
